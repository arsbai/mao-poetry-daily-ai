# 向东 · Android 1.1

每天读一句毛泽东诗词，欣赏对应书法；按情境寻找有出处的原句，点开阅读整首诗或完整著作。

## 安装与使用

将 `XiangDong-1.1.apk` 传到安卓手机，点击安装，按手机提示允许从当前文件管理器安装。支持 Android 8.0 及以上版本。这是供体验的测试签名安装包；本次使用与 1.0 相同的签名，可以覆盖更新并保留本机设置和收藏。

1. **今日**：每天按日期选择一句诗，展示平台对应书法；点击“读完整首”查看整首诗、出处与书法。也可以再读一句、收藏。
2. **寻句**：输入“我现在遇到困难了，很难过”“描述凯旋而来的句子”“描述不要乱改变方向的句子”等内容，查找原句；可筛选诗词或著作。
3. **原典**：按篇名或正文搜索，完整阅读、查看来源，管理收藏。
4. **我的**：填写模型地址、模型名称、API 密钥，保存连接。返回寻句，勾选“用大模型理解情境”。

不填密钥可以离线阅读和检索已收录文字。书法配图需要联网；它们只用于展示，未下载进原文资料包，也不发送给大模型。

## 桌面组件与锁屏

首页标题区现在只显示横排日期。其他已有阅读和检索界面保持原有设计。

在安卓应用的 **我的 → 桌面与锁屏** 中使用新增功能：

1. **添加每日一句组件**：点击后在系统桌面提示中添加。也可以长按桌面空白处，在小组件列表选择“向东 · 每日一句”。组件显示当天选句、日期和篇名，点击正文打开对应原诗；右上角圆箭头可刷新。长按组件可调整宽高，字体随空间缩放，小尺寸时收起篇名。
2. **一句话与书法设为锁屏**：使用首页当前展示的句子及配套书法，先打开构图预览，再点击“设为锁屏”。可以先在首页点击“再读一句”，然后返回这里选择另一句。

锁屏按当前设备的屏幕比例生成：书法采用等比例完整显示，宽幅在空间允许时匹配屏幕宽度，竖幅和长卷在可用高度内缩放。空余区域取样纸张边缘的颜色，向下渐变为深红色；诗句与篇名使用黑色，上方预留时钟区域。系统接口只设置锁屏。每次设置生成一张静态锁屏，换句后可再次预览并设置。

组件独立读取本机文字库，无需模型密钥或联网；按本机日期切换，午夜安排一次非精确更新，并由系统定期刷新。省电、强行停止、桌面软件限制可能推迟更新，点击组件刷新箭头或重新打开应用可刷新。系统不支持快捷添加时，请使用桌面的小组件列表。

锁屏首次读取对应书法需要网络，最近几份原图仅缓存在应用缓存中，不进入文字知识库。无需相册或存储访问权限。网页预览只展示功能入口，组件与系统锁屏操作需在安卓应用中完成。

## 模型连接

兼容 `/chat/completions` 接口，预置 DeepSeek、通义千问，可自定义服务。地址填写到服务的版本根路径即可，不必重复填写 `/chat/completions`。

| 服务 | 地址示例 | 模型示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问（北京兼容域名） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |

通义也可填写控制台提供的业务空间专属域名。地域、密钥和模型名称应与你的服务配置一致。参考 [DeepSeek 官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/) 与 [阿里云官方兼容接口说明](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)。

应用先让模型把处境转换成检索词，再从本机原文中找候选，让模型挑选并解释。最终显示的原句始终取自原文；候选编号会校验，重复或不存在的编号会丢弃。模型失败时保留本地结果，找不到相关原文时显示无匹配。

这是**原文知识库加检索增强**，没有修改或微调模型权重。安卓端密钥通过 Android Keystore 加密保存，关闭应用后仍可使用；网页预览的密钥只留在当前页面会话内。只有主动开启模型寻句才发送本次输入及少量候选上下文。应用没有内置密钥，也没有代为调用付费服务。

## 原文资料

本次资料包含：

- 指定平台 **67 条诗词记录**，对应 **63 份不同的诗词全文**；平台对几组组诗存在重复记录，阅读目录保留来源条目，检索与导出知识库去重。
- **222 篇本人著作、讲话、书信和访谈答语**，取自毛泽东选集文字目录。
- 合计约 **94 万字符**；去重后 **285 份原文**，导出 **1,761 个知识片段**。

来源：

- [毛泽东文献数字资源平台](https://www.dlmzd.net/)：只提取诗词库中 `AUTHOR=毛泽东` 的 `MFULLTEXT`；书法仅保存关联地址。
- [中文马克思主义文库·毛泽东](https://www.marxists.org/chinese/maozedong/index.htm)：选集目录所载原文转录，非网站自己的研究文章。作者归属、篇目和版本依据来源记录，未进行手稿级校勘。

编者导语、脚注、平台鉴赏注释、访谈中的记者提问、已识别的合著和共同署名作品、PDF、图片、音视频、研究论文均不进入文字知识库。毛泽东本人著作内的引文属于所载正文，不将引文另行标为毛泽东的独立语录。当前资料包并非毛泽东全部著作全集；未通过格式或作者范围校验的条目保留在采集报告中。

每篇原文带有篇名、日期、来源链接、版本说明和 SHA-256 校验值。核心数据：

| 文件 | 用途 |
|---|---|
| `corpus/txt/` | 按篇阅读的 UTF-8 纯文字 |
| `corpus/originals.jsonl` | 去重的原文与出处，可用于知识库导入 |
| `corpus/rag_chunks.jsonl` | 按原文切分的知识片段，含原文起止位置 |
| `corpus/poems.json`、`texts.json` | 来源条目与元数据 |
| `corpus/*-report.json` | 数量、采集时间、未收录条目与原因 |

## 每日更新

安卓端使用系统 JobScheduler，在有网络时约每 24 小时检查诗词；重启手机后任务仍保留。打开应用也会检查当天是否更新。“我的 → 现在更新诗词”可以手动更新。

系统后台调度受省电、休眠、网络和厂商限制，无法保证在某个固定时刻执行；强行停止应用后，通常需再次打开应用恢复调度。更新失败或正文数量异常时保留上一份可用原文。收藏仍保存在本机。

没有配置书房服务时，安卓端直接访问指定平台公开诗词接口，以约每秒一次的节奏读取正文；不会尝试绕过登录或访问控制。如果平台未来要求登录或变更接口，需要调整采集器。

如需手机关闭时仍持续采集，可将附带的 Python 服务部署在常开主机上，在“我的”中填写 HTTPS 服务地址和令牌。服务只负责原文库更新，模型仍由你配置的服务提供。

## 电脑预览与采集

需要 Python 3.10+，只使用标准库，无需安装 Python 依赖。在解压后的源码目录执行：

```powershell
python backend/server.py --port 8765
```

然后打开 `http://127.0.0.1:8765/`。也可运行 `Start-Preview.ps1`。预览应通过本机服务打开，直接双击 HTML 文件无法可靠加载资料。

更新文字与知识库：

```powershell
python backend/collect.py poems
python backend/collect.py texts --limit 250
python backend/normalize.py
python backend/export_rag.py
```

`collect.py` 自动处理旧网页 GB2312/GBK 标签与实际 GB18030 编码，遵循已读取的 robots 抓取间隔；默认只获取有限选集篇目。`repair.py` 可重试采集报告中的失败条目，完成后再次执行 normalize 和 export_rag。

常开服务：

```powershell
$env:XIANGDONG_SERVER_TOKEN = '设置你自己的长随机令牌'
python backend/server.py --host 0.0.0.0 --port 8765 --daily
```

远程使用需要 HTTPS 反向代理；服务绑定非本机地址前必须配置令牌。安卓端填入同一令牌。日程按中国标准时间的自然日检查；服务未运行时不会继续采集。本地预览默认不启动每日采集。

## 安卓源码与构建

`android/` 是可导入 Android Studio 的 Java 工程，使用系统 WebView 承载打包在应用内的阅读界面，原生部分实现加密密钥、模型请求、公开诗词同步和后台调度。没有服务器也能运行已收录的原文库。

工程编译 SDK 35，最低 SDK 26。Android Studio 可打开 `android/`，同步 Gradle 后运行。也提供无需 Gradle 的独立打包脚本，需自行准备官方 JDK 17、Android Build Tools 35.0.0 和平台 `android.jar`：

```powershell
python build_apk.py --jdk "你的JDK目录" --tools "你的build-tools/35.0.0目录" --android-jar "你的platforms/android-35/android.jar" --output "build/XiangDong-1.1.apk"
```

脚本在本机构建目录生成测试签名。正式分发应使用你自己的发布签名，并按目标市场要求做真机、后台行为与隐私审核。
